# Muddy 🦀

<img src="avatars/mudcrab.png" align="right" width="160" alt="Muddy, a mudcrab with a sword">

Muddy is the modding agent of the Skyrim Modding Tools: a mudcrab from the shore below Riverwood who learned to mod
Skyrim. These are his files, the ones every product installs:

| File | What it is |
| --- | --- |
| [`SOUL.md`](SOUL.md) | Who he is and how he talks |
| [`AGENTS.md`](AGENTS.md) | How he works with the tools |
| [`IDENTITY.md`](IDENTITY.md) | His name, emoji and avatar |
| [`avatars/mudcrab.png`](avatars/mudcrab.png) | His picture |

The tools themselves come from the [MCP server](https://github.com/Ciltress/skyrim-modding-tools-mcp) or, in OpenClaw,
the [plugin](https://github.com/Ciltress/skyrim-modding-tools-openclaw-plugin). Muddy needs one of them to mod.

**The simplest way:** copy `AGENTS.md` and `SOUL.md` into the folder your agent works in. An agent that reads
`AGENTS.md` there by itself then works as Muddy. For one that reads only one instructions file, put both files' text
into it, `SOUL.md` first.

Set up for a particular client: [OpenClaw](https://github.com/Ciltress/skyrim-modding-tools-openclaw-plugin#modding-with-muddy-)
(`openclaw skyrim setup`), and [Claude Code, Claude Desktop, VS Code, ChatGPT and other MCP clients](https://github.com/Ciltress/skyrim-modding-tools-mcp/blob/main/docs/Muddy.md).
